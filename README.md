
# TORRETA ROBOTICA TDM

Proyecto desarrollado con PIC18F4550.

Software:
- MikroC PRO for PIC 7.6.0
- Proteus 8
- GitHub

Componentes:
- PIC18F4550
- Cristal de 20 MHz
- Dos servomotores
- Sensor HC-SR04
- Pantalla LCD 16x2
- Pulsador
- LED indicador

Objetivo:
Desarrollar una libreria propia para controlar
los servomotores y el sensor ultrasonico.
